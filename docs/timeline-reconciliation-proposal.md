# 《钢铁共和国》时间线冲突解决提案

版本：`SR-TIMELINE-RECONCILIATION-v1.0`

状态：`APPROVED PLAN / NON-CANONICAL`

用途：记录全局 Canon 与卷一生产草案之间的时间差异、推荐处理方式和待作者确认事项。本文档不改变任何正式设定。

## 1. 判定规则

时间线优先级按项目根目录 `AGENTS.md` 执行：

1. `canon/timeline/master-timeline.md`
2. 卷级生产文件
3. 章节草稿中的具体日期

因此，在作者正式批准前，全局 Canon 保持不变；卷一日期视为草案，不得反向覆盖 Canon。

## 2. 已确认的冲突

| 事件 | 全局 Canon | 卷一草案 | 处理判断 |
|---|---:|---:|---|
| 周衡进入旧工业区 | 未定 | SE 0 | 可保留为卷内起点，暂不提升为全局事件 |
| 周衡发现 404 | 未定 | SE 1 | 可保留为卷内暂定日期 |
| 404 第一次启动 | SE 3 | SE 2；第一章写 SE 1 | 以 Canon 为准，章节改为 SE 3 或相对时间 |
| 废铁营建立 | SE 5 | SE 3 | 以 Canon 为准，卷内顺延至 SE 5 |
| 陈默档案公开 | SE 10 | 第二章提前出现相关档案 | 区分“私人/隐藏档案线索”和“公开档案事件” |
| 第一代拓荒者原型完成 | SE 20 | SE 8 | 以 Canon 为准，移至 SE 20 |
| 民间制造开始 | 未写入全局 Canon | SE 15 | 暂列 `PROPOSAL`，不得当作已确认事实 |
| 创造者争论爆发 | 未写入全局 Canon | SE 20 | 暂列 `PROPOSAL`，需安排在原型完成之后 |
| 协议建立 / 拓荒者理念公开 | Canon 为 SE 30“理念公开” | 卷内为 SE 30“协议建立” | 先区分“理念公开”和“正式协议”，协议日期待确认 |

## 3. 推荐方案：Canon 优先，草案顺延

推荐采用方案 A：

```text
SE 0   周衡进入北方旧工业区（卷内起点，暂不提升为全局 Canon）
SE 1   周衡发现 404（卷内事件）
SE 3   404 第一次启动（全局 Canon）
SE 5   废铁营建立（全局 Canon）
SE 10  陈默档案公开；此前可有私人档案碎片或未公开副本
SE 20  第一代拓荒者原型完成（全局 Canon）
SE 20  之后再展开创造者责任争论（暂定）
SE 30  拓荒者理念公开（全局 Canon）
SE 30+ 正式责任协议日期另行确认
```

该方案的优点：

- 不需要改动已经标为 Canon 的百万年总时间线；
- 保留第一章“发现—启动”的戏剧顺序；
- 让“原型完成 → 民间扩散 → 责任协议”符合技术和社会演化顺序；
- 将未确认事件明确隔离为提案，避免后续章节把草案误当事实。

## 4. 对现有章节的最小修改

在方案 A 获批准后，建议按以下顺序处理：

1. `chapter-001-404.md`：把“SE 1”改为“SE 3”，或改成“钢铁纪元初期（具体年份待定）”。
2. `timeline.md`：将 404 启动改为 SE 3、废铁营建立改为 SE 5；保留其他未确认日期为 `PROPOSAL`。
3. `chapter-002-last-repairman.md`：将陈默材料定义为私人/隐藏档案，不与 SE 10 的“公开”冲突。
4. `chapter-003` 及后续章节：不要使用 SE 8 作为原型完成时间，改用“数年后/原型阶段”。
5. 在协议章节确定前，不把“SE 30 正式协议建立”写入 Canon；先使用“理念公开”或“协议草案”。
6. 完成全卷日期替换后，再做一次人物年龄、技术可得性和事件先后顺序审查。

## 5. 不推荐方案

### 方案 B：反向修改全局 Canon

把全局事件整体提前到 SE 1—SE 3。该方案会影响第四卷前的所有引用、人物年龄和技术发展间隔，除非作者明确要重写历史，否则不采用。

### 方案 C：新增“第七码头地方历法”

用地方年份解释 SE 1/SE 2。该方案可以保留数字，但会增加第二套历法和叙述负担，容易造成新的跨章节误读，暂不采用。
