- **ch120《未勾的纸》**：北轨被记录为一台本地未知有限设备，状态标 `待继续`；废铁营从「地点」转为「可传递的公共维修关系」；手递入口／北轨交接作为 **OPEN 问题**留给后续卷，vol2 以独立章节承接，不依赖本章前提。

**优点**：与 ch116—117 风格与事实连续；改动最小；vol1 在留白中收束，跨区议题自然外溢到 vol2—4。

### 路线 B ——「桥接移交」（收缩为本地尾声，跨区整体后移）

ch118—120 收缩为一段紧凑的本地尾声，只把手边已确立的本地项（未勾的纸、本地无404日实践、五项关系）移交 vol2；跨区材料整体删除，vol2 ch001 成为真正桥梁。

**代价**：放弃 ch118—120 原有篇幅与部分人物弧光，需在 vol2—4 补回。

### 路线 C ——「反向立论」（把失效前提变成叙事选择）

ch118—120 改写为：社区**主动选择**本地维修关系、**拒绝** centralized 跨区网络——即把旧稿的「跨区网络／四节点」作为被提出并**刻意否决**的方案，使其成为 vol2—4 去中心化文明的主题种子。

**优点**：不丢失旧稿张力，反而把 BLOCKED 前提转化为主题资产。
**代价**：需谨慎避免「否决」本身变成新的 canon 承诺；否决应保持为局部、可重新协商。

**推荐**：以**路线 A 为骨架**，在 ch119 融入**路线 C 的「刻意不选 centralized 网络」** framing；路线 B 作为若作者希望卷末更薄时的备选。
