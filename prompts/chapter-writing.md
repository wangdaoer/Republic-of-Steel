# 章节写作 Prompt

状态：`DRAFT / TEMPLATE`

## 输入

- 卷名与章节编号
- 章节契约
- 相关 Canon 文件
- 角色当前状态
- 时间线位置
- 必须推进的伏笔

## 指令

根据输入生成章节草稿。必须遵守 `AGENTS.md`，不得将 `PROPOSAL` 或 `DRAFT` 当作既定事实。

章节必须包含：

1. 开场冲突
2. 人物选择
3. 世界变化
4. 核心理念冲突
5. 主题推进
6. 伏笔结尾

## 输出格式

```text
状态：DRAFT
章节目标：
时间与地点：
视角人物：
核心冲突：
人物选择：
世界变化：
主题推进：
伏笔连接：
正文：
待审问题：
```
