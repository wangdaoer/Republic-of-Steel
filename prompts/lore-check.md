# 世界观一致性检查 Prompt

状态：`DRAFT / TEMPLATE`

## 检查范围

1. 时间线是否连续
2. 技术是否已在该时代出现
3. 文明与势力路线是否一致
4. 术语是否使用统一名称
5. 章节事件是否改变社会、人物或制度
6. 伏笔是否有来源与回收记录

## 输出状态

- `PASS`：未发现冲突
- `REVIEW`：存在需要人工判断的风险
- `BLOCKED`：与 Canon 明确冲突，禁止进入正式正文

## 输出格式

```text
章节：
检查版本：
结论：PASS / REVIEW / BLOCKED
时间线问题：
技术问题：
文明问题：
术语问题：
伏笔问题：
建议行动：
```
