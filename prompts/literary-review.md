# 独立文学审稿 Prompt

状态：`DRAFT / TEMPLATE`

用于对《钢铁共和国》既有章节做独立文学复审。此模板只输出诊断、证据和建议；不得自动修改正文、Canon、章节状态或台账。

## 输入

- 章节编号、标题、正文版本与其**来源状态**
- 本章章节契约，以及上一章结尾与下一章承接义务
- 相关 Canon、时间线、人物状态/知识边界、伏笔和事实台账
- 本章涉及的物件、资源、关系、承诺与禁止事项
- 本项目风格约束与本次复审重点
- 如有：状态不一致的来源及其适用范围

## 审稿指令

1. 先找故事压力、人物选择、因果链中的三个最大问题，再谈字句。
2. 以可核查的章节段落、台账条目或 Canon 文件作为证据；`DRAFT`、`PROPOSAL` 和模型推断不能当作既定事实。
3. 审查文本是否从行动、物件、空间、对话和代价进入现场，避免把情绪、主题和因果直接讲解给读者。
4. 对每个问题选择一项处理决定：`PATCH`（局部修补）、`REWRITE`（按原契约重写关键段落/章节）或 `REPLAN`（先重订章节契约、承接或下游计划）。
5. 发现 Canon、时间线、人物知识边界或既有承诺的明确冲突时，结论为 `BLOCKED`；不得静默给出替代事实。
6. `PASS` 仅表示本次审稿无阻塞项；任何 `ACCEPTED` 标记、台账回写或下游状态更新都必须等待作者明确确认。

## 输出格式

```text

审稿版本：
来源状态：
上下文包版本：
结论：PASS / REVIEW / BLOCKED
状态待确认（如有）：来源、冲突状态、适用范围、待作者决定事项

一、三项诊断
1. [故事压力/人物选择/因果链]：问题、证据、影响
2. [故事压力/人物选择/因果链]：问题、证据、影响
3. [故事压力/人物选择/因果链]：问题、证据、影响

二、处理决定
- 决定：PATCH / REWRITE / REPLAN
- 最小修订范围：
- 保留项与不可改动项：

- 一致项：文件/章节锚点与说明
- 风险或冲突：文件/章节锚点、证据等级、建议状态
- 人物知识、资源、物件、关系、伏笔与时间线影响：
```

## 结论边界

- `PASS`：未发现阻塞项，仍保持输入中的正文状态。
- `REVIEW`：保留风险、证据和修订建议，等待讨论或修订。
- `BLOCKED`：先处理 Canon 或连续性冲突，不能以审稿意见代替作者决定。

审稿者不得把 `DRAFT`、`REVIEW_REQUIRED` 或 `COMPLETE / DRAFT` 自动提升为 `ACCEPTED` 或 `CANON`。
