# 第一卷：《废铁营》

版本：`SR-VOL01-v1.0`

状态：`OUTLINE / PRODUCTION_READY`

## 基本信息

- 卷名：《废铁营》
- 英文：*Waste Iron Camp*
- 主题：创造力量
- 时间：钢铁纪元0—30年（卷内时间线仍需与全局 Canon 对齐）
- 地点：北方旧工业区
- 主角：周衡

## 核心角色

404号机甲、韩朔、顾言、苏烈、陈默。

## 核心问题

普通人是否拥有创造未来的资格？

## 核心冲突

旧工业体系认为制造能力应该集中；废铁营理念认为创造能力应该被更多人拥有。

## 最终结果

拓荒者时代开启。

## 第一卷核心句

> 我们修好的不是一台机器，而是一种可能。
