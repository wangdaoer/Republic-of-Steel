# Volume 01 Writing Rules

## 生产状态

本卷计划与章节草稿默认属于 `OUTLINE` 或 `DRAFT`，不能自动升级为 `CANON`。

## Canon优先级

先参考项目根目录 `canon/`、全局时间线和人物档案；卷内文件不得静默覆盖全局 Canon。

发现冲突时：

1. 保留证据；
2. 在 `timeline.md` 或 `review.md` 记录；
3. 标记为 `REVIEW_REQUIRED` 或 `TBD`；
4. 等待作者确认后再回写全局设定。

## 主角规则

### 周衡

- 不追求权力。
- 不成为救世主。
- 通过选择改变世界。
- 永远优先寻找第三种可能。

### 404

- 不战斗优先。
- 不反抗人类。
- 优先帮助、修复与连接。

## 剧情规则

每章必须包含：

1. 一个具体事件；
2. 一个价值冲突；
3. 一个未来伏笔；
4. 至少一项人物、社会或制度变化。

## 文风

强调工业细节、人物选择与哲学问题；避免单纯升级、无意义战斗和技术炫耀。

## 章节验收

章节必须经过：章节契约 → 初稿 → 人物检查 → 世界观检查 → 独立审稿 → `ACCEPTED`。
