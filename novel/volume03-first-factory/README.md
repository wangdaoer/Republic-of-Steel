# 第三卷：《第一工厂》

版本：SR-VOL03-v1.0

状态：PRODUCTION / DRAFT

主题：工业的所有权与创造者责任。

时间范围：SE 160—350。

## 卷级命题

第二卷问：当创造能力进入战争，文明如何不只剩下生产和胜负。

第三卷问：当战争结束、工业重新扩张，谁有权决定机器如何生产、谁承担自动化的代价，以及创造者是否只拥有成果而不承担后果。

第一工厂不是一座建筑。

它是把维修能力、学校、档案、资本、国家、工人和机器重新放进同一张关系图的试验。

## 生产边界

- 国家、资本和工人都拥有真实能力与真实代价，不设置单一纯恶反派。
- 自动化不是简单的进步或灾难，必须写出隐形劳动、培训、岗位迁移和公共分配。
- 工厂智能不是万能AI，不替人类自动解决所有责任。
- 创造者协议不是禁止创新，而是让拥有成果的人承担可追索、可暂停和可修复的责任。
