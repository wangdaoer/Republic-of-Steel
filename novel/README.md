# 小说正文库

状态：`COMPLETE / DRAFT / LITERARY_REVIEW`

正文必须在核心设定、章节契约和连续性检查完成后进入本目录。

四卷共 240 章初稿已建立；默认工作是独立文学复审、卷级回读和作者验收，不应因本页而自动继续第一卷的批量生产。

## 当前创作入口

1. 作者指定某章或某卷后，先读取其内嵌章节契约、前章结尾、相关 Canon、卷内人物/时间线/伏笔/审稿台账。
2. 先给出故事压力、人物选择和因果链的三项诊断，再决定局部修订、重写建议或暂停重规划。
3. `PASS` 不自动变为 `ACCEPTED`；只有作者明确接受的正文才能回写持久台账。
4. 若根目录、项目计划与卷级台账的状态描述不一致，记录为 `REVIEW_REQUIRED`，不得静默选择其一作为新事实。

详细流程见 [小说创作接入说明](../docs/novel-skill-integration.md)，逐章复审使用 [文学审稿模板](../prompts/literary-review.md)。
