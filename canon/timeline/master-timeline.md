# 《钢铁共和国》历史时间线

版本：`SR-Timeline-v1.0`

状态：`Canonical`

## 时间体系说明

本世界采用钢铁纪元（Steel Era），简称 `SE`。

## 第一纪元：工业觉醒时代

### 时间：SE -200 至 SE 0

#### 文明状态

人类进入高度工业化阶段。

主要力量：国家、大型企业、工业联盟。

#### 技术特点

拥有自动化生产、高级机械系统和初级人工智能。

#### 社会结构

制造能力高度集中，普通人主要负责使用和维护。

#### 核心矛盾

创造能力是否应该属于所有人？

#### 关键人物

陈默。

#### 历史意义

陈默提出创造能力开放理念，为废铁营时代埋下思想基础。

## 第二纪元：废铁营时代

### 时间：SE 0—SE 30

#### 起点事件

404 号机甲在北方旧工业区被发现。

#### 核心人物

周衡。

#### 重要事件

| 时间 | 事件 | 意义 |
|---|---|---|
| SE 3 | 周衡第一次启动 404 | 404 恢复基础运行，机器第一次主动请求维修 |
| SE 5 | 废铁营建立 | 保存维修知识 |
| SE 10 | 陈默档案公开 | 维修不仅是技术，也是文明责任 |
| SE 20 | 第一代拓荒者原型完成 | 修复理念进入可制造阶段 |
| SE 30 | 拓荒者理念公开 | 进入新时代 |

## 第三纪元：拓荒者时代

### 时间：SE 30—SE 120

#### 核心变化

制造能力扩散，普通人开始拥有设计、制造和改造能力。

#### 主要力量

- 共和国：国家协调力量；
- 星环工业：资本推动效率；
- 自由拓荒者：个人创造自由；
- 工业网络：共享协作。

#### 关键事件

| 时间 | 事件 | 代表/意义 |
|---|---|---|
| SE 45 | 第一台民间拓荒者出现 | 林川；普通人成为创造者 |
| SE 60 | 创造者责任争论 | 开放制造的责任边界进入公共讨论 |
| SE 75 | 《拓荒者责任协议》建立 | 责任制度形成 |
| SE 100 | 第一工业冲突发生 | 多方力量直接竞争 |
| SE 120 | 拓荒者时代进入战争阶段 | 制造能力转化为文明战争能力 |

## 第四纪元：北境战争时代

### 时间：SE 120—SE 160

#### 战争起因

帝国认为开放制造导致文明失控。

#### 战争特点

这不是单纯军事战争，而是文明模式竞争。

#### 重要事件

| 时间 | 事件 | 意义 |
|---|---|---|
| SE 125 | 断链战争开始 | 帝国攻击工厂、知识库和教育体系 |
| SE 135 | 维修军团建立 | 维修成为战略能力 |
| SE 145 | 雾岭工业城撤离 | 文明从土地转向人 |
| SE 150 | E-100 超级机甲计划启动 | 旧时代力量的最后反扑 |
| SE 155 | E-100 失败 | 不是技术失败，而是无法形成支持体系 |
| SE 160 | 北境战争结束 | 战争模式与文明定义改变 |

## 第五纪元：第一工业时代

### 时间：SE 160—SE 350

#### 核心问题

和平时代如何建设未来？

#### 第一工业城建立：SE 180

模式：三权工业体系，包括国家、企业和劳动者。

#### 重要发展

| 时间 | 事件 |
|---|---|
| SE 220 | 人工智能进入工业 |
| SE 250 | 自动化革命开始 |
| SE 280 | 智能资本体系形成 |
| SE 320 | 工业 AI 治理出现 |
| SE 350 | 《创造者协议》建立 |

## 第六纪元：智能文明时代

### 时间：SE 350—SE 1000

#### 核心事件

AI 从工具发展为文明参与者。

#### S-00 发展阶段

| 时间 | 事件 | 身份/变化 |
|---|---|---|
| SE 400 | S-00 诞生 | 工业智能 |
| SE 500 | S-00 参与创造 | 从工具进入协作 |
| SE 700 | 高级智能协议建立 | 智能参与受到责任约束 |
| SE 900 | AI 文明参与讨论 | AI 成为文明关系主体 |
| SE 1000 | 人类进入星际时代 | 从行星文明迈向星海 |

## 第七纪元：星海拓荒时代

### 时间：SE 1000—SE 5000

#### 核心变化

人类离开太阳系。

#### 重要接触文明

| 文明/存在 | 主题 |
|---|---|
| 阿尔塔文明 | 完美导致停滞 |
| 伊诺文明 | 自由需要动力 |
| 观察者文明 | 文明记录与传承 |
| 凯洛文明 | 完美管理与选择 |
| 无尽智能 | 无限答案与未知 |

#### 重要事件

| 时间 | 事件 |
|---|---|
| SE 1200 | 拓荒者一号启动 |
| SE 1500 | 发现阿尔塔遗迹 |
| SE 2000 | 星海协议建立 |
| SE 3000 | 人类拒绝完全融合无尽智能 |
| SE 5000 | 钢铁共和国理念成为星海原则 |

## 第八纪元：文明修复时代

### 时间：SE 5000 以后

#### 核心变化

钢铁共和国不再是政治实体，而成为文明行为准则。

#### 主要机构

星海修复网络。

#### 职责

帮助文明恢复发展能力。

## 第九纪元：第五文明时代

### 时间：SE 100000 以后

#### 特点

新文明继承钢铁共和国理念，但不复制旧制度。

核心：创造自己的未来。

## 第十纪元：回声时代

### 时间：SE 500000 以后

#### 特点

钢铁共和国成为宇宙文化符号，不再属于任何文明，而成为一种选择。

## 最终历史总结

钢铁共和国的发展路线：

废铁 → 维修 → 创造 → 责任 → 智能 → 文明连接 → 宇宙修复。

最终原则：

> 文明不是永远正确。
>
> 文明是永远能够修正。
